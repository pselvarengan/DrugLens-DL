# DrugLens-DL

DrugLens-DL is an explainable AI-based web platform for drug-likeness prediction.

## Features
- ECFP4 + physicochemical descriptors
- LightGBM classifier
- Lipinski & Veber rules
- SHAP-based interpretability
- Web interface (Streamlit)

## Usage
1. Enter SMILES or upload CSV
2. Obtain AI probability and rule-based assessment
